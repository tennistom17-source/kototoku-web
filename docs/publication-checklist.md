# 公開前チェックリスト

公開前に毎回確認します。1つでも判断に迷う項目があれば公開せず、`要確認` とします。

## 情報管理

- [ ] 本業、勤務先、顧客、社内システム、業務データ、未公開情報を含まない。
- [ ] 本名、住所、メールアドレス、注文番号、家族の個人情報、顔写真を含まない。
- [ ] スクリーンショット・動画の個人情報と特定情報をマスクした。
- [ ] 特定の事業者名や画面名は、必要がなければ一般化した。

## 内容・権利

- [ ] 体験事実、感想、改善案を分けた。
- [ ] 断定的な批判や不確かな仕様・価格・機能を掲載していない。
- [ ] 最新情報が必要な箇所は公式情報で確認した。
- [ ] 画像、動画、文章、引用の著作権・利用規約を確認した。
- [ ] 広告や紹介リンクがあれば明確に表示した。

## 公開後の負担

- [ ] 長時間の個別対応、会議、重い保守を前提にしていない。
- [ ] サンプル・試作品の範囲と注意点を明記した。
- [ ] リンク先、見出し、表示内容を確認した。
- [ ] 運営者が公開を承認した。
