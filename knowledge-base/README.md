安全に再利用できる気づき、検証結果、アイデアを残す非公開の作業用メモです。本業、勤務先、顧客、社内情報、未公開情報、個人を特定できる出来事は記録しません。迷う場合は保存せず `要確認` とします。

## 追加前の確認

1. 本業・社内・顧客情報を含まない。
2. 本名、住所、メールアドレス、注文番号、顔写真などを含まない。
3. 公開候補は、事実・感想・改善案を分ける。
4. 公開可否が不明なら `要確認` とする。

## 短い入力テンプレート

【種別】体験／アイデア／検証結果／失敗／AI費用ログ
【一言】
【誰のどんな困りごと】
【分かったこと・仮説】
【再利用先】日記／ツール／動画／商品案／台帳
【公開可否】公開可／要マスク／非公開／要確認
【本業・個人情報チェック】問題なし／要確認
【次の一歩】30〜60分でできること
