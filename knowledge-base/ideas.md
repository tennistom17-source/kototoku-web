# アイデア受信箱・評価方法

思いつきは商品化を決めず、まずここに登録します。公開、支出、外部連絡は運営者の承認後に行います。

## 受信箱

| アイデア | 誰のどんな困りごと | 販売・公開の形 | 初回作成時間 | 保守負荷 | 法務・規約リスク | 収益化の仮説 | 次の小さな一歩 | 状態 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  | 低／中／高 |  |  | 30〜60分の検証 | 受信箱 |

## 評価方法

各案について、次を短く確認します。

1. 誰の手間・不安・失敗を減らすか。
2. サンプル級で価値を試せるか。
3. 長時間の対応や重い保守を必要としないか。
4. 個人情報、規約、著作権、誤案内のリスクを減らせるか。
5. 無料集客、単品販売、セット販売のどれを仮説にするか。

評価できない項目は `要確認` とし、推測で埋めません。
