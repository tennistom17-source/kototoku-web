# kototoku-web
「できるを、もっと身近に。」個人がAIと一緒に小さなWebプロジェクトを育てる記録サイト。

このサイトは実在企業の公式サイトではありません。個人が運営する実験的なWebプロジェクトです。
「AI仮会社」に登場するメンバーは実在の社員ではなく、AIの役割設定を分かりやすくするための架空の設定です。

## ページ構成

- `index.html`：ホーム。サイトの概要と各ページへの導線カード、小さなツール（準備中）を掲載。
- `diary.html`：つくる日記。顔も会社名も出さずに、AIと一緒に小さな挑戦を始める記録。
- `ai-company.html`：AI仮会社。運営者が社長として最終判断だけを行う、架空のAIチーム設定を紹介。
- `faq.html`：よくある質問。GitHub Pagesでの公開やAI仮会社についてのQ&A。

## 変更概要（2026年更新）

- サイトのコンセプトを「個人がAIと一緒に小さなWebプロジェクトを育てる記録サイト」に更新。
- 会社概要風の表現・所在地・連絡先など、実在企業を連想させる記載を削除。
- 共通のナビゲーション・フッターを全ページで統一し、ホーム / つくる日記 / AI仮会社 / 小さなツール / よくある質問への導線を追加。
- `diary.html`・`ai-company.html`・`faq.html` を新規作成。
- AI仮会社の似顔絵はすべてオリジナルの抽象SVGイラスト（同一絵柄、色のみ部署ごとに変更）とし、alt相当の説明を付与。
- 各ページに「実在の社員ではない」「AIは自律的な人格を持たない」旨の注記を明記。

## 確認したこと

- 相対リンク（各ページ間のリンク、`index.html#tools` の同一ページ内リンク）に切れがないことをスクリプトで確認済み。
- `target="_blank"` を使用する外部リンク（GitHub Pages公式ドキュメント）には `rel="noopener noreferrer"` を付与済み。
- 個人情報の入力欄、会員登録、お問い合わせフォーム、ログイン機能は追加していない。
- 外部画像URLや著作権のある素材は使用せず、似顔絵イラストはインラインSVGのみで構成。
- 既存の「白と青を基調とした」配色・静的HTML構成（GitHub Pagesでの配信）を維持。
