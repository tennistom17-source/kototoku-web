# kototoku-web
「できるを、もっと身近に。」個人がAIと一緒に小さなWebプロジェクトを育てる記録サイト。

このサイトは実在企業の公式サイトではありません。個人が運営する実験的なWebプロジェクトです。
「AIチーム」に登場するメンバーは実在の人物ではなく、AIの役割設定を分かりやすくするための架空の設定です。

## ページ構成

- `index.html`：短い目次と紹介動画。無料ツール・日記・AIチーム・運営方針・FAQへ直接移動。
- `about.html`：コトトクについて。運営の仕組み、活動ログの状況、今後の方針、安心への取り組みを見出しごとに開閉。
- `assets/css/home-index.css`：ホーム・目次と運営紹介専用のスタイル。共通CSSや各ツールの見た目には影響させない。
- `diary.html`：つくる日記。個人情報を出さずに、AIと小さな挑戦を始める記録。
- `ai-company.html`：AIチーム。運営者が最終判断を行う、架空の役割設定。既存URLを維持。
- `faq.html`：よくある質問。GitHub Pagesでの公開やAIチームについてのQ&A。
- `site-map.html`：閲覧者向けのサイト案内。各ページ・主要セクションを部屋に見立てたフロアマップ。全ページのナビゲーションから移動できる。
- `ai-model-compare.html`：生成AI・モデル比較と使い方診断。回答はブラウザ内だけで点数化し、保存・送信しない。
- `ai-prompt-translator.html`：AIへの頼み方 翻訳機。質問の回答からAIへの依頼文を組み立てる。
- `site.css` / `site.js`：全ページ共通のデザインとメニュー・動画エラー表示処理。

## しんどさ可視化ツール

- [shindosa_visualizer.html](shindosa_visualizer.html)：場面14種・相手9種・気持ち12種を単一選択し、6本のスライダーで今の状態を整理する独立したHTMLです。外部ライブラリ・履歴保存・Cookie・アクセス解析・自動送信は使用しません。このページにはGA4タグを追加しないでください。
- スコアは医学的な指標ではありません。負荷25・疲れ15・緊張17・納得できなさ17・急ぎ13・動かせる感13の重みで、最初の5項目は「入力値-1」、最後は「5-入力値」として合計し、4で割って四捨五入します。範囲は0〜100で、選択した場面や気持ちを病気・危険度へ換算しません。
- Canvasの6軸は入力値そのものです。「動かせる感」が外側でも悪化を意味しません。チャート下のテキストでも各値を確認できます。
- 「プロンプトをコピー」はクリップボードへのコピーだけです。「ChatGPTを開く」を押した場合のみ、プロンプトをURLエンコードして `https://chatgpt.com/?q=` へ渡します。移動先の規約・保存設定が適用され、URLはブラウザ履歴に残る場合があります。
- ホーム・サイト案内から移動できます。単独でHTMLを開いても動作します。ローカルファイルでコピーが許可されない場合は、表示されたプロンプトを選択してコピーしてください。

## AI比較診断

- `assets/css/ai-model-compare.css`：比較ページ専用のレスポンシブスタイル。
- `assets/js/ai-model-compare.js`：用途・予算・経験・重視点の4項目がそろうと自動診断し、選択変更で再計算。回答リセット、データ取得失敗時の再試行に対応。回答は保存・送信しない。
- 月額予算は無料・3,000円・1万円の選択に加え、「予算を自分で指定」で円単位の上限を入力できる。0円は無料候補、空欄・負数・小数は未完了として扱う。金額の入力で自動再計算し、品質の希望は「重視したいこと」で別に指定する。
- `assets/js/ai-model-compare-core.js`：無料・有料候補の分離、プランの用途対応、予算判定、サービス別の暫定適合値による候補順を管理。有料プランは重視点に対応するプランを優先し、同条件では安いものを各サービスから1つ選ぶ。高額な上位プランは比較表で確認できる。
- `data/models.json`：サービスごとの `plans` に無料・有料のモデル名、価格、通貨、主な違い、利用条件、対応用途を登録。2026-09-14に公式料金ページで22プランを確認。Microsoft Copilotは取得時にサインイン画面へ移動し、料金未確認の1行として掲載、診断には含めない。
- ChatGPT FreeはGPT-5.6 Luna、Plusの通常チャットはGPT-5.6 Sol、PlusのWork / CodexはGPT-6 Astra・Sol・Terra等と区別。通常チャットのGPT-6 ProはProなど対象プラン。価格ページの概略を公式ヘルプの利用場所別説明で補足する。プラン内の全モデルを網羅するものではない。
- モデル名と利用場所は、各プランの利用モデル・主な違いと利用条件に記載する。ChatGPT PlusのWork / Codexで使えるGPT-6 Astraと、通常チャットのGPT-6 Proは区別し、プラン表から確認できる。
- `price` は元通貨の請求金額。通常は月払い、`billing: "annual"` は年払い総額。年払いは月額相当額と年払い総額を併記する。`price: null` は料金未確認のため有料診断から除外する。
- `usd_to_jpy: 150` は比較用の仮レートであり実勢レートではない。月3,000円・月1万円の判定にはこの換算値を使用し、税・為替・年払い条件を画面にも明記する。開始価格のプランは `price_from: true` とする。
- `data/scoring-rules.json`：用途・予算・経験・重視点の重みとサービス別加点を管理。「現在使っているもの」とその加点は削除した。
- レーダーとバブルは廃止。棒は選んだ用途について各サービスの暫定設定値を0〜100で表示し、数値と長さが一致する。実測性能・正答率・公式評価ではなく、プランやモデルの性能差も表さない。日常の相談には文章・企画の設定値を使う。
- 比較表はサービスと無料・有料で絞り込み可能。用途セレクターは棒グラフの比較用途を切り替え、表はそのサービスの全用途のプランを掲載する。スマホでは各行を縦に表示する。
- 自動更新は選択に応じた診断結果の更新であり、公式価格や新モデルを自動収集して書き換えるものではない。外部API、APIキー、追加の実行時ライブラリは不要。

### 比較診断のテスト

リポジトリ直下で `node --test assets/js/ai-model-compare.test.cjs` を実行する。4項目での判定、無料予算、有料予算、用途不一致、年払い換算、GPT-6の有料提案を検証する。
ブラウザでは4項目を選択した後の自動再計算、リセット、読込失敗からの再試行、比較フィルター、320px・390px・1440px幅での表示を確認する。

### 自動更新

- `scripts/update_models.py` は、各データの `source_url` だけを取得する。公式ページを安全に構造化して確認できない場合、モデル名・料金・提供状況・能力値を推測で書き換えない。
- 取得失敗時は `models.json` の `last_checked` を更新せず、標準出力と `data/update-log.json` に取得失敗理由を残す。能力値は自動更新しない。
- 新しいモデルの自動追加もしない。人が公式情報を確認して該当サービスの `plans` に追加し、出典と確認日を更新する。プランやモデル名の変更から能力値を推測しない。未確認の料金・提供内容を診断候補に含めない。
- `.github/workflows/update-model-data.yml` は毎日1回（UTC 02:17）と手動実行でPythonを実行する。`models.json` に検証済みの差分が発生した場合だけ、更新ログとともに自動コミット・pushする。今回の運用では、この自動公開を明示的な例外として採用している。
- 実行失敗はGitHubの `Actions` からワークフロー `Update official AI model data` を開き、`Check official sources and update safe fields` のログを確認する。Actionがpushできない時は、リポジトリの `Settings` → `Actions` → `General` で `Workflow permissions` の書き込み権限を確認する。
- ローカルで確認する場合は、リポジトリ直下で `python scripts/update_models.py` を実行する。比較画面はJSON読み込みがあるため、`python -m http.server 8765 --bind 127.0.0.1` で配信して確認する。

## 組織紹介の更新（2026-09-14）

- 白と青を基調に、AIの作業は青、人の判断は緑、記録と学びはローズで区別。ノート・虫眼鏡・確認印・本をHTML/CSSで図案化。
- 作業の6工程はPCで横並び、1000px以下では順序を追いやすい縦並び。図は運用方針であり、自律稼働の実績ではない。
- 公開ルールを維持し、「AIチーム」とイニシャルのみ使用。公開済みの5名の役割を紹介し、全10名の紹介へリンク。人物画像は両ページとも役割を表す小物図案へ変更。内部名簿・モデル設定・管理ログは転載しない。
- 活動ログは日時・担当AI・提案・社長の判断の4列。4項目を確認できる公開用記録がないため準備中とし、例示の日時や活動を掲載しない。追加時は根拠と公開承認を確認する。
- 日記の3つの抜粋は公開済み記事の要約。`diary.html#day-000` と `diary.html#day-001` へ直接リンク。
- 組織・日記・ツール・信頼・将来の収益化の関係図を追加。ツールや収益は実績ではなく、準備中・検討段階と明記。
- JavaScriptが無効でも本文とナビゲーションを表示。動きを減らす設定に対応。既存の計測タグは変更していない。

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

- ローカルHTTP配信で動画の再生・シークを確認。動画通信を失敗させた場合のエラー案内も確認。
